# Pyschology_Manager
A psychology appointment manager that allows you to track your sessions


A simple CLI (terminal) appointment manager made with Python for psychologists.  
It allows you to register patients, schedule sessions, manage appointments, and calculate total income.

## ✨ Features
- View registered patients
- Add new patients
- Edit patient information
- Delete patients
- Schedule sessions
- View all sessions
- View sessions by patient ID
- Mark sessions as completed
- Cancel/delete sessions
- Calculate total income from completed sessions
- Automatic saving/loading using JSON database

##  Requirements
- Python 3.x
